# learn-nextjs

A practice repository for learning **Next.js** fundamentals and core concepts.

This project follows a course taught by Bob Ziroll from Scrimba and covers essential features of modern Next.js applications, including routing, rendering strategies, and performance optimization.

---

## 📚 Course Instructor

**Bob Ziroll**  
Platform: Scrimba  

---

## 🚀 Course Curriculum

### 1. Creating a Next.js App
- Setting up a new Next.js project
- Understanding project structure
- Running the development server

### 2. File-Based Routing (Including Nested Routes)
- How Next.js handles routing automatically
- Creating nested routes
- Organizing routes effectively

### 3. Optimising Fonts and Images
- Using Next.js built-in font optimisation
- Image optimisation with the `next/image` component
- Improving performance and Core Web Vitals

### 4. Difference Between a Page and a Layout
- Understanding what a **page** is
- Understanding what a **layout** is
- Sharing UI between routes
- Layout nesting concepts

### 5. Client vs Server Components
- What are Server Components?
- What are Client Components?
- When and why to use each
- Performance implications

### 6. Dynamic Routes
- Creating dynamic route segments
- Accessing route parameters
- Building dynamic pages

### 7. Rendering Strategies
- **SSG (Static Site Generation)**
- **ISR (Incremental Static Regeneration)**
- **SSR (Server-Side Rendering)**
- Choosing the right rendering strategy
